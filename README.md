# Anju Portfolio

## Project Overview

This portfolio website is built with React, Vite, and Tailwind CSS. The project focuses on modern responsive design, custom font styling, and polished footer visual details.

## Current Progress

- Initialized the app with Vite and React
- Configured Tailwind CSS using `@tailwindcss/vite`
- Added custom font imports for `Roboto`, `Poppins`, `Libre Baskerville`, and `Ephesis`
- Built a responsive footer component in `src/components/footer/Footer.jsx`
- Styled footer message with `Libre Baskerville` and highlighted text using `Ephesis`
- Added a decorative accent icon with pulse and hover animation
- Implemented responsive layout for mobile, tablet, and desktop
- Created inline white SVG icons for footer contact details and social links

## Design Tokens

- Primary color: `#152e3a`
- Secondary color: `#fbf1df`
- Accent color: `#a64321`

## Fonts

- Button and general text: `Roboto`
- Footer main phrase: `Libre Baskerville`
- Footer highlight span: `Ephesis`
- Secondary font utilities: `Poppins`

## Key Files

- `package.json` — dependencies and scripts
- `vite.config.js` — Vite configuration
- `src/index.css` — global styles and font imports
- `src/components/footer/Footer.jsx` — responsive footer layout and styling

## Available Scripts

- `npm run dev` — start development server
- `npm run build` — build production assets
- `npm run preview` — preview production build
- `npm run lint` — run linting

## Notes

The footer is designed to be mobile-first and visually distinctive, with responsive stacking, a creative callout phrase, and cohesive white icon styling.
